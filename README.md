# AI-VL — ecosystem

**Wrapper** repo: it groups the launchers (`win/`, `linux/`) and the documentation to
install and run the whole system. It **does not contain the app code** — the three
app repos are independent (each its own `.git`) and are git-ignored here (see
`.gitignore`); you clone them inside this folder.

## Architecture

Three independent apps that talk to each other **over the network (by port), never by
file path** (each one can run on a different machine):

```
frontend (phone)  →  backend (:8443 HTTPS)  →  iacore (:8001)  →  Ollama (:11434, model)
   browser UI           gateway / API+WS        YOLO + VLM          qwen3-vl:4b-instruct
```

- **iacore** (`AI-VL-core`) — inference core: YOLO + VLM and the heavy deps
  (torch/ultralytics). Exposes `service:app` on `:8001`.
- **backend** (`AI-VL-backend`) — gateway the browser connects to (WS for the video
  stream). Relays frames to iacore. No model deps. `app:app`.
- **frontend** (`AI-VL-frontend`) — minimalist browser UI. Talks only to the backend.
  React + Vite, built with `bun`.

## Repos to clone

Clone the three **inside this folder** (keep the folder names):

```bash
git clone https://github.com/Maxi-Andres/AI-VL-core.git      AI-VL-core
git clone https://github.com/Maxi-Andres/AI-VL-backend.git   AI-VL-backend
git clone https://github.com/Maxi-Andres/AI-VL-frontend.git  AI-VL-frontend
```

| Repo | URL | Role |
|------|-----|------|
| `AI-VL-core`     | https://github.com/Maxi-Andres/AI-VL-core.git     | iacore — YOLO + VLM (`:8001`) |
| `AI-VL-backend`  | https://github.com/Maxi-Andres/AI-VL-backend.git  | gateway — API + WS (`:8443`) |
| `AI-VL-frontend` | https://github.com/Maxi-Andres/AI-VL-frontend.git | browser UI |

## Ports

| Service | Port | Notes |
|---------|------|-------|
| iacore  | 8001  | Local HTTP (YOLO/VLM detection) |
| backend | 8443  | HTTPS (phone mode); serves the frontend on a single origin |
| Ollama  | 11434 | model `qwen3-vl:4b-instruct` |

## Quick start

1. Clone the three repos inside this folder (see above).
2. Depending on your OS, use the launchers (they auto-detect the repo root, so they
   work from the subfolder or moved to the root):
   - **Windows** → [`win/`](win/README.md): `install.bat` (once) and `run.bat`.
   - **Linux** → [`linux/`](linux/README.md): `./install.sh` (once) and `./run.sh`.

Both install whatever is missing (Python, Bun, Ollama), build the venvs, compile the
frontend and bring everything up in **phone mode (HTTPS)** so you can use the phone as
a camera. The launchers **do not touch git**: they respect each repo's branch/commit.
